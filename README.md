# Team Directory App

A React and Tailwind CSS team directory application built for the Team Directory App laboratory activity.

## Features

- Five React Router routes: Home, Users, User Details, About, and 404 Not Found
- Local user data with 8 team members
- Reusable Navbar, UserCard, Button, Loader, and ErrorMessage components
- User search by name, email, or company
- Favorite users with a favorites count in the Navbar
- Dark mode using React state and localStorage
- User details using `useParams`
- Dynamic document titles using `useEffect`

## Technologies

- React
- Vite
- Tailwind CSS
- React Router

## Run Locally

```bash
npm install
npm run dev
```

Open the local development URL shown in the terminal.
